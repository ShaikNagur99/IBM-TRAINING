# Mini Banking App

A simple console-based banking application built with Java 17+ features such as records and switch expressions.

## Features
- Create accounts
- Deposit money
- Withdraw money
- Transfer funds between accounts
- View accounts and transactions

## Run
```bash
mvn compile exec:java -Dexec.mainClass=com.example.bankingapp.BankingApp
```

## Test
```bash
mvn test
```
